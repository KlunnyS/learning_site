# Grammar Source Policy

The grammar path is inspired by Tae Kim's Guide to Japanese Grammar, especially its beginner-friendly ordering of topics.

Do not copy large lesson text from Tae Kim or any other copyrighted source. NihongoPath grammar entries should use original short explanations, original example sentences, and original exercises.

Each grammar item should clearly link to the relevant source when a source influenced the curriculum order or topic selection. Seeded grammar uses `source_name` and `source_url` fields for this.

Acceptable content:

- A short original explanation
- Original Japanese example sentences
- Original practice prompts
- Links to Tae Kim pages or other sources

Avoid:

- Long copied explanations
- Reproduced lesson sections
- Copied exercise sets
